## 1

(a) P(A ∩ B) = P(A)P(B) = 0.4 × 0.3 = **0.12**.

(b) P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
= 0.4 + 0.3 − 0.12 = **0.58**.

## 2

P(A | B) = 0.7 ≠ P(A) = 0.5.

**A and B are not independent**, because independence requires P(A | B) = P(A) when P(B) > 0.

## 3

P(Aᶜ) = 1 − 0.6 = 0.4.

P(B) = P(B | A)P(A) + P(B | Aᶜ)P(Aᶜ)
= 0.5 × 0.6 + 0.2 × 0.4 = 0.38.

P(A | B) = P(B | A)P(A) / P(B)
= (0.5 × 0.6) / 0.38 = 15/19 ≈ **0.78947**.

## 4

Let D = having the disease and + = a positive test.

P(Dᶜ) = 1 − 0.02 = 0.98.

P(+ | Dᶜ) = 1 − 0.90 = 0.10.

P(+) = P(+ | D)P(D) + P(+ | Dᶜ)P(Dᶜ)
= 0.95 × 0.02 + 0.10 × 0.98 = 0.117.

P(D | +) = P(+ | D)P(D) / P(+)
= (0.95 × 0.02) / 0.117 = 19/117 ≈ **0.16239 (16.24%)**.

## 5

(a) E[X] = Σ x P(X = x)
= 85(0.375) + 90(0.375) + 95(0.125) + 100(0.125)
= 31.875 + 33.750 + 11.875 + 12.500 = **90**.

(b) E[X²] = 85²(0.375) + 90²(0.375) + 95²(0.125) + 100²(0.125)
= 2709.375 + 3037.500 + 1128.125 + 1250.000 = 8125.

Var(X) = E[X²] − (E[X])² = 8125 − 90² = **25**.

(c) Sample mean = (85 + 90 + 85 + 95 + 90 + 85 + 100 + 90) / 8
= 720 / 8 = **90**, which equals E[X].

## 6

(a) H(X) = −Σ p(x) log₂ p(x)
= −[0.4 log₂(0.4) + 0.3 log₂(0.3) + 0.2 log₂(0.2) + 0.1 log₂(0.1)]
= 0.528771 + 0.521090 + 0.464386 + 0.332193
≈ **1.84644 bits**.

(b) Each message has probability 1/4.

H(X) = −4 × (1/4) × log₂(1/4) = −1 × (−2) = **2 bits**.
